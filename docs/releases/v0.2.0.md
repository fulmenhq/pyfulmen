# Release v0.2.0 - 2026-01-05

**Release Type**: Minor - Crucible v0.3.2 Integration & CI/CD Modernization
**Release Date**: January 5, 2026
**Status**: Ready for Release

**Summary**: PyFulmen v0.2.0 aligns with Crucible v0.3.2's role-based agentic model, modernizes the bootstrap and CI/CD infrastructure to match gofulmen/rsfulmen patterns, and adds dependency protection (license compliance and supply chain security).

## Breaking Changes

None. This release is backward compatible.

## New Features

### License Audit & Dependency Protection

New `make license-audit` target checks dependencies for forbidden licenses:

```bash
make license-audit
# Auditing dependency licenses...
# No forbidden licenses detected
```

New `.goneat/dependencies.yaml` configuration:

- Forbidden licenses: GPL, LGPL, AGPL, MPL, CDDL
- Allowed licenses: MIT, Apache-2.0, BSD-\*, ISC, PSF-2.0
- Package cooling policy (7-day minimum age for supply chain security)
- Serde-class exemptions for pydantic, pyyaml

### Foundation Tools Scope

`.goneat/tools.yaml` expanded with Python-specific foundation tools:

- uv (package manager)
- ruff (linter/formatter)
- actionlint, ripgrep, jq, yq, yamlfmt

## Changes

### Role-Based Agentic Model

Migrated from identity scheme to Crucible v0.3.2 role catalog:

| Old (Identity)       | New (Role)      |
| -------------------- | --------------- |
| @pyfulmen-architect  | `devlead` role  |
| @schema-cartographer | `infoarch` role |
| @fulmen-ea-steward   | `entarch` role  |

Updated files:

- `AGENTS.md` - Role-based model with commit attribution including `Role:` trailer
- `MAINTAINERS.md` - Role catalog references

### Bootstrap Modernization

Aligned with gofulmen/rsfulmen patterns:

```bash
make bootstrap
# -> sfetch self-verify (trust anchor)
# -> Installing goneat v0.4.1 via sfetch
# -> Installing foundation tools via goneat doctor
# -> Syncing Python dependencies with uv
```

Key changes:

- New `scripts/make-bootstrap.sh` for clean trust pyramid
- BINDIR defaults to `$HOME/.local/bin` (not `./bin`)
- Uses `goneat doctor tools --scope foundation`

### Hook Configuration

`.goneat/hooks.yaml` updated:

- Pre-push now includes `dependencies` category
- Explicit `--hook-manifest` flag for config resolution
